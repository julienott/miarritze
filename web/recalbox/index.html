Le jeu de combat de Biarritz, sur ta Recalbox, à la manette, sur la télé. Il se met à jour tout seul : quand une nouvelle version sort, elle se télécharge au lancement du jeu.

Installer en 4 étapes

  1. Télécharge le fichier .zip de ta machine avec le bouton rouge, sur un ordinateur.
  2. Ouvre le dossier share de la Recalbox. La Recalbox allumée et branchée au même réseau : sous Windows, tape \\RECALBOX dans la barre d'adresse de l'explorateur ; sur Mac, Finder, menu Aller > Se connecter au serveur, puis smb://recalbox. Ouvre share.
    Sans réseau : éteins la Recalbox, branche sa carte SD (ou son disque) sur l'ordinateur et ouvre la partition SHARE.
  3. Décompresse le .zip dans share. Il ajoute roms/ports/miarritze (le jeu) et system/.emulationstation/systemlist.xml (qui fait apparaître le jeu).
    Si le dossier system/.emulationstation contenait déjà un systemlist.xml, ne l'écrase pas : copie seulement le bloc <system … miarritze …> du nôtre dans le tien, avant </systemList>. Ou utilise l'installation par SSH ci-dessous, qui le fait toute seule.
  4. Redémarre la Recalbox (menu Start > Quitter > Redémarrer). Le jeu est dans Ports.

Jouer

Manettes : les manettes configurées dans Recalbox marchent directement, deux joueurs sur la même console. Le clavier marche aussi.

Quitter : maintiens Select (ou le bouton Hotkey/Home) et Start ensemble une seconde. Le jeu revient à la liste des jeux.

Mises à jour : automatiques, au lancement, si la Recalbox a Internet. L'écran affiche « Nouvelle version du jeu ! », puis le jeu redémarre tout seul. Sans Internet, il démarre normalement.

Sauvegardes : dans share/saves/ports/miarritze, jamais effacées par les mises à jour.

Pour les parents

Aucune donnée personnelle n'est demandée : un pseudo et, pour jouer en ligne, un code de groupe.

Installation par SSH (plus rapide si tu connais) : ssh root@recalbox (mot de passe par défaut recalboxroot), puis
curl -fsSL https://miarritze.ijulien.com/recalbox/install.sh | bash
Le script choisit la bonne version, vérifie le téléchargement, ajoute le jeu à un systemlist.xml existant et redémarre EmulationStation.

Ça ne démarre pas ? Le journal du jeu est dans share/system/logs/miarritze-borroka.log.

Désinstaller : supprimer share/roms/ports/miarritze et le bloc miarritze de share/system/.emulationstation/systemlist.xml (ou ce fichier entier s'il ne contenait que lui).

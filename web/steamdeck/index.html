Miarritze Borroka sur Steam Deck

Le jeu de combat de Biarritz, à installer sur ta Steam Deck. Il se met à jour tout seul : quand une nouvelle version sort, elle se télécharge au lancement du jeu.

Installer en 6 étapes

  1. Passe en mode Bureau. Appuie sur le bouton STEAM, choisis Alimentation, puis Passer au Bureau.
  2. Ouvre cette page dans le navigateur de la Deck (Firefox ou Chrome) et appuie sur le bouton rouge Télécharger l'installation.
  3. Ouvre le dossier Téléchargements (l'icône de dossier en bas de l'écran, puis Téléchargements).
  4. Lance l'installation : fais un clic droit (gâchette L2) sur installer-miarritze.sh, choisis Propriétés, onglet Droits d'accès, coche Est exécutable, valide avec OK. Puis double-clique sur le fichier et choisis Exécuter.
    Une fenêtre dit « C'est installé ! » quand c'est fini. Ça peut prendre une minute.
  5. Ajoute le jeu à Steam s'il n'y est pas déjà : ouvre Steam, menu Jeux > Ajouter un jeu non-Steam à ma bibliothèque, coche Miarritze Borroka, puis Ajouter la sélection.
  6. Reviens en mode Jeu avec l'icône Retour au mode Jeu sur le Bureau. Le jeu est dans ta Bibliothèque, onglet Non-Steam.

Pour les parents

Le jeu s'installe dans ~/Games/MiarritzeBorroka, sans mot de passe administrateur. Aucune donnée personnelle n'est demandée : un pseudo et, pour jouer en ligne, un code de groupe.

Plutôt au clavier ? Dans l'application Konsole, cette commande fait la même installation :
curl -fsSL https://miarritze.ijulien.com/steamdeck/install.sh | bash

À chaque lancement, le jeu regarde s'il existe une version plus récente sur ce site. Sans Internet, il démarre normalement. Pour désinstaller : supprimer le dossier ~/Games/MiarritzeBorroka et le raccourci dans Steam.

# Checklist iPhone (à faire par Julien sur un vrai appareil)

En mode autonome, ces points sont couverts par Playwright WebKit en émulation (844×390, tactile). Ils restent à valider sur un vrai iPhone :

- [ ] Le jeu se charge en paysage (Safari), sans écran noir.
- [ ] Portrait → overlay « Tourne ton appareil », pause ; retour paysage → reprise.
- [ ] Encoche et barre d'accueil : aucun bouton ni élément du HUD masqué.
- [ ] Multitouch : joystick + 2 boutons en même temps.
- [ ] Glisser d'un bouton à l'autre (POING → SPÉCIAL) sans lever le doigt.
- [ ] Audio audible après le premier geste.
- [ ] 10 combats d'affilée sans crash mémoire.
- [ ] Super au pad (bouton MARÉE et tap à deux doigts en mode gestes).
- [ ] Combat en ligne iPhone ↔ Mac sur le même Wi-Fi, puis en 4G.
- [ ] Clavier virtuel pour le pseudo.
